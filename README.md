# 우리 반 직업 신청

학급 직업(1인 1역)을 학생들이 직접 신청하고, 선생님이 번호순으로 정리해 문서로 받아 볼 수 있는 웹앱입니다.
**구글 시트에 얹어 배포하면 주소 하나로 학급 전체가 각자 태블릿에서** 신청할 수 있습니다.

## 무엇을 할 수 있나요

| 대상 | 할 수 있는 일 |
| --- | --- |
| 학생 | 이름·번호를 적고, 직업별 하는 일·인원·횟수를 읽은 뒤 **1~3지망**을 골라 제출 |
| 학생 | 번호·이름이 **명부와 맞아야** 제출 가능 (틀리면 바로 알려 주고 막습니다) |
| 학생 | **한 번호로 한 번만** 신청 가능. 제출 후에는 자기가 고른 내용을 다시 볼 수 없음 (수정도 불가) |
| 교사 | 비밀번호를 넣고 신청 현황을 **번호순**으로 확인 |
| 교사 | **자동 배정** — 1지망부터 차례로, 정원이 넘치면 무작위 추첨 |
| 교사 | 결과를 **워드 문서(.doc)** 또는 **엑셀(CSV)** 로 내려받기 |
| 교사 | 아직 안 낸 학생이 누구인지 한눈에 확인 |
| 교사 | 학생 명부 등록, 직업 이름·인원·횟수·설명 편집, **매달 초기화** |

- 처음 들어 있는 직업 목록(돌쇠, 칠가이, 편돌이, 안나, 배민, 피카츄, 테트리스, 사스코, 스즈메, 중계당,
  영미신, 교머니) 12종과 하는 일·인원·횟수는 **2026. 6. 15. 표준근로계약서(양념반후라이드반)** 를
  그대로 옮긴 것입니다. [교사용] → [직업 관리]에서 언제든 고칠 수 있습니다.
- 인원은 계약서에서 그 직업을 맡았던 학생 수를 그대로 넣었습니다(모두 합쳐 22명). 이번 달에 맞게 조정해 주세요.
- **모둠장**은 다른 직업과 겹쳐서 맡는 역할이라 신청 목록에서 뺐습니다. 따로 정해 주세요.

## 먼저 할 일 — 학생 명부 넣기

배포를 마쳤으면 **[교사용](비밀번호 3051) → [설정·초기화] → [학생 명부]** 칸에 한 줄에 하나씩 `번호 이름` 형식으로
붙여넣고 [명부 저장하기]를 누르세요.

```
1 김도현
2 김민승
3 김진우
```

- 명부를 넣어 두면 학생이 **번호나 이름을 잘못 적었을 때 제출되지 않고**, 적는 즉시 알려 줍니다.
  띄어쓰기는 무시하므로 `오 선우` 도 통과합니다.
- 명부를 비워 두면 확인 없이 누구나 제출할 수 있습니다(다른 학급에서도 쓸 수 있도록).
- 이미 신청한 번호를 적으면 **"이미 신청을 마쳤어요"** 가 뜨고 제출 단추가 잠깁니다.
  태블릿을 바꾸거나 브라우저 기록을 지워도 서버가 막아 줍니다.
- 명부는 **선생님 구글 시트**(파일만 열어 쓰는 경우에는 그 브라우저)에만 저장되며, 매달 초기화해도 지워지지 않습니다.
- 이 저장소는 공개 상태라 학생 실명을 코드에 넣지 않았습니다. 명부는 선생님이 직접 넣어 주세요.

## 쓰는 방법 1 (권장) — 구글 시트에 얹어 배포하기

배포 한 번이면 **주소 하나**로 학생·교사가 모두 들어옵니다. 신청 내용은 선생님 구글 시트에 쌓입니다.

1. 구글 드라이브에서 **새 스프레드시트**를 만듭니다. (예: "우리 반 직업 신청")
2. 메뉴 **[확장 프로그램] → [Apps Script]** 를 엽니다.
3. 기본으로 있는 `Code.gs` 내용을 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 를 전부 붙여넣습니다.
4. 왼쪽 **[파일] 옆 [+] → [HTML]** 로 파일을 추가하고 이름을 반드시 **`index`** 로 한 뒤,
   그 안의 내용을 모두 지우고 [`index.html`](index.html) 을 전부 붙여넣습니다. (저장: Ctrl+S)
5. 오른쪽 위 **[배포] → [새 배포] → 유형 [웹 앱]**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
6. 나오는 **웹 앱 주소(.../exec)** 가 곧 우리 반 신청 주소입니다. 학생들에게 알려 주세요.
   선생님도 같은 주소로 들어가 오른쪽 위 [교사용]을 누르면 됩니다.

> 처음 배포할 때 구글이 권한을 물어봅니다. [고급] → [안전하지 않은 페이지로 이동] 을 눌러 허용해 주세요.
> 본인이 만든 스크립트라 뜨는 안내입니다.
>
> 코드를 고친 뒤에는 **[배포] → [배포 관리] → 연필 → 버전 "새 버전" → [배포]** 를 해야 반영됩니다.

이 방식에서는 결과 문서를 내려받을 때 **선생님 드라이브의 `직업 신청 결과` 폴더에 저장**되고 바로 열립니다.
(구글이 웹 앱 화면을 틀 안에 넣어 돌리기 때문에 브라우저 내려받기가 막힐 수 있어서입니다)

## 미리 보기 — 파일만 열어 보기

`index.html` 을 더블클릭하면 배포 없이 화면을 둘러볼 수 있습니다.
다만 신청 내용이 **그 브라우저에만** 저장되고 기기끼리 모이지 않으므로, 실제 신청에는 쓰지 마세요.
한 기기에서는 한 번만 제출할 수 있고, 다시 받으려면 [교사용] → [전체 초기화]가 필요합니다.

## 매달 초기화

**[교사용] → [설정·초기화] → [전체 초기화]** 를 누르고 `초기화` 라고 입력하면,
그달의 신청 기록과 배정 결과가 지워지고 학생들이 새로 신청할 수 있게 됩니다.
직업 목록·학생 명부·설정은 그대로 남습니다.

- 지우기 전에 **[먼저 문서로 내려받기]** 로 기록을 보관하세요.
- 구글 시트에 얹어 쓰는 경우, 초기화할 때 `보관_날짜` 시트로 **사본이 자동 저장**됩니다.

## 자동 배정 규칙

1. 학생 순서를 무작위로 섞습니다.
2. **1지망**부터 봅니다. 정원보다 신청자가 적으면 모두 배정, 많으면 **무작위 추첨**으로 뽑습니다.
3. 떨어진 학생은 **2지망**, 그다음 **3지망** 순서로 같은 방식을 반복합니다.
4. 지망한 직업이 모두 찬 학생은 **미배정**으로 남습니다. 배정 표에서 선생님이 직접 지정할 수 있습니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 전체 (HTML·CSS·JS 한 파일). Apps Script에는 `index` 라는 HTML 파일로 넣습니다 |
| `apps-script/Code.gs` | 구글 시트 저장·화면 서빙을 맡는 Apps Script 코드 |

## 메모

- 교사용 비밀번호는 **3051** 로 고정되어 있습니다. 바꾸려면 `index.html` 의 `TEACHER_PIN` 값을 고치세요.
  (공유 모드를 쓴다면 `apps-script/Code.gs` 의 `TEACHER_PIN` 도 같은 값으로 맞춰야 합니다)
- 비밀번호가 앱 안에 들어 있으므로, 페이지 소스를 열어 보면 확인할 수 있습니다. 학생이 아주 마음먹고 찾으면
  볼 수 있다는 뜻이니, 꼭 감춰야 하는 내용은 담지 마세요.
- 내려받는 파일 이름은 `class-jobs_2026-09.doc` 처럼 영문으로 만들어집니다.
  (일부 브라우저가 한글 파일 이름을 버리고 확장자 없는 파일로 저장해 버리기 때문입니다. 문서 안의 제목은 한글 그대로입니다)
- `.doc` 파일은 한글(HWP)·워드·구글 문서에서 모두 열립니다.
